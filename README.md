### Overview

Created an engaging web page for photo management and user profiles using JavaScript, HTML, and CSS. This project features dynamic photo management capabilities, including adding, removing, and liking photos, all presented through a visually appealing grid layout. Enhanced the user experience with smooth modal transitions and ensured seamless operation across devices with a responsive design tailored for both desktop (1280px) and mobile (320px) views, inspired by Figma mockups.

## Getting Started

### 1. Clone the Repositories

    First, clone the front-end repository to your local machine:

```
git clone https://github.com/raymondafan/se_project_aroundtheus.git
```

## 2. Set Up the Project

    Navigate to the front-end repository and install the dependencies:

```
cd se_project_aroundtheus
```

```
npm install
```

Start the front-end development server:

```
npm run dev
```

Make sure that:

- The package.json file exists in the se_project_aroundtheus directory.
- The package.json file includes a dev script, typically something like "dev": "vite" or "dev": "react-scripts start".

## 3. View the Application

You can view the application by navigating to:

http://localhost:8080
